# OriginX Structure Engine — Phase 2 Closure

## Status

PHASE 2 — OriginX Structure Engine is complete.

The Structure Engine transforms a validated public identity package into a complete, schema-valid and canonically hashable `OX-ART-SPEC-1`.

It does not generate images, load image models, compile diffusion prompts or execute external providers.

## Canonical pipeline

Identity Input
→ StructureInput validation
→ deterministic seed
→ tier / era rules
→ OriginX Art Rule Catalog
→ structured semantic assembly
→ OX-ART-SPEC-1 validation
→ canonical serialization
→ artSpecHash

## Identity Input boundary

The Structure Engine accepts only public or technical identity data:

- tokenId
- serial
- canonicalName
- tier
- generationTheme
- DNA
- dnaHash
- Resonance
- optional explicit seed

The Structure Engine must not receive buyer email, buyer identity, payment information, private order identifiers or authentication tokens.

## Tier evolution

RARE → Primitive Origin
EPIC → Evolved Origin
LEGENDARY → Ascended Origin

Evolution is structural and artistic. It is not merely an increase in glow, ornament or visual noise.

## Determinism

Canonical structural selection is hash-based and namespace-separated.

For identical identity input, canonical versions, rules and seed, the Structure Engine reproduces the same canonical Art Spec and the same `artSpecHash`.

This is specification-level determinism.

Future image inference is not assumed to be byte-identical across different models, runtimes, hardware or numerical backends.

## Visual hierarchy

MACRO > MESO > MICRO

Anatomy, silhouette, physical mass, pose and composition have priority over secondary and microscopic detail.

Microdetail must never conceal incorrect anatomy.

## Resonance

Resonance is narrative and artistic metadata.

It may influence spectrum, energy topology, accent geometry, atmospheric behavior and lighting rhythm.

Resonance is narrative only. It is not a physical measurement.

## Governance

CANDIDATE != APPROVED ART
QUALITY SCORE != FINAL AUTHORITY
RESONANCE != PHYSICAL MEASUREMENT

Canonical artwork approval remains manual.
