# Phase 12 — Canonical Output Manifest

Phase 12 introduces a canonical output manifest for promoted candidates.

The manifest binds:

- canonical id
- candidate id
- output artifact id
- output artifact SHA-256
- provenance manifest digest
- promoted decision evidence
- canonical ledger index

This phase still does not move binary files, publish image assets, or execute generation. It only produces the JSON contract required before later canonical output workflows.
