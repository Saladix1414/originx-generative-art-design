# Local Generator Phase 13 — Runtime Command Plan Contract

This phase defines `OX-RUNTIME-COMMAND-PLAN-1`.

The command plan is intentionally not executable:

- executable is null;
- argv is empty;
- cwd is null;
- environment is empty;
- shell is not allowed;
- network is not allowed;
- backend invocation is false;
- model execution is false.

This phase does not construct real commands, execute models, call runtimes,
generate media, call networks, or approve canonical artwork.
