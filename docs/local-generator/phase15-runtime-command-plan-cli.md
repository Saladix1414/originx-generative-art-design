# Local Generator Phase 15 - Runtime Command Plan CLI Inspection

This phase exposes the declared runtime command plan through a read-only CLI command.

Command:

    oxgad runtime-command-plan

The command emits an OX-RUNTIME-COMMAND-PLAN-1 payload with command construction, backend invocation, shell execution, network access, and model execution disabled.

No runtime is invoked.
No model is executed.
No image is generated.
