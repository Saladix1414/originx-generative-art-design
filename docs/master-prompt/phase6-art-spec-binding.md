# Master Prompt Phase 6 — Art Spec Binding

Phase 6 binds the Master Prompt builder to existing OX-ART-SPEC-1 and OX-RENDER-1 documents.

The binding derives:

- art spec hash
- render plan hash
- rarity band
- composition profile
- render intent
- runtime target
- seed

This phase still does not execute models, call network services, generate images, publish outputs, or move artifacts.
