# Master Prompt Phase 10 — Quality Profile

Phase 10 adds a local quality profile for `OX-MASTER-PROMPT-1`.

The profile evaluates:

- positive prompt completeness
- negative prompt completeness
- macro detail coverage
- meso detail coverage
- micro detail coverage
- trait coverage
- local-first safety coverage
- validation gate result

This is not visual QA and does not execute models or generate images.
